Ironbook 是一款健身房黑板风格的训练记录 App:铁上的粉笔和胶带,破纪录时用金色。

记录永久免费。Pro 一次买断,没有订阅。

训练日志最重要的,就是站在杠铃前时知道上次练了多少。Ironbook 把这个数字放在每一组旁边,在锁屏上运行休息计时,并画出一路向上的曲线。

永久免费
• 训练、模板和历史记录不限数量
• 每组都显示上次的重量和次数;留空直接打勾,就自动填入上次的数字
• 锁屏和灵动岛上的休息计时,时间到了会震动提醒
• 自动算好热身组:空杆、40%、60%、80%
• 画出杠铃的配片计算,按单边显示,支持 kg 和 lb
• 每个动作都能写笔记,下次练同一个动作时会显示上次的笔记
• 每周目标和按周计算的连续记录,每月一次免费的连续记录护盾
• 训练结束页会点出你的每一个 PR
• 前三项纪录,以及主屏幕上的小号周小组件

IRONBOOK PRO(一次买断)
• 进步曲线:预估 1RM 变化、金色标出的 PR 训练、每次训练的最大重量组、每周训练容量
• 完整的纪录墙,以及每个动作的每一次训练
• 训练计划库:5x5、推拉腿、上下肢分化、每周三练全身、纯哑铃
• 将训练保存到健康 App
• 显示最新 PR 和下次训练内容的大号周小组件
• 所有组导出为 CSV

小额附加内容(单独购买)
• Next Block:根据你自己的最好成绩,为每个动作设好目标的四周模板。容量、积累、大重量、减载。每个点数生成一个周期
• PR 海报:把新 PR 做成金色黑板海报,三张一组
• 周护盾:在每月免费的一次之外,练得少的那一周也能保住连续记录
• 胶带配色:Cobalt、Volt、Rose、Bone,各配一款 App 图标
• 每次破纪录都有 PR 烟花

支持 kg 和 lb。无需账户,没有广告,没有追踪。训练记录只保存在你的 iPhone 上。

※ 目前 App 内界面为英文。
